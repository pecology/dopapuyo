# どぱぷよ

上級者向けの連鎖スコアアタック。目標点に到達するまでの最速タイムを競う。
ルールとスコア計算はぷよぷよeスポーツ（通ルール）準拠。配ぷよはぷよぷよeスポーツのチャレンジモードの性質（8手ごとに色の数がそろう）に合わせて独自に生成する。仕様は [requirements.md](requirements.md) を参照。

> 非公式のファンメイド作品です。株式会社セガとは関係ありません。非商用で公開しています。

**プレイはこちら: https://pecology.github.io/dopapuyo/**

## 遊び方

| 操作 | 矢印キー方式（デフォルト） | 直接指定方式 |
|---|---|---|
| 移動 | `←` `→` | ― |
| 回転 / 向き | `Z` `X` | `W` `A` `S` `D`（子ぷよの向き） |
| 設置 | `↓` または `↑` | `H` `J` `K` `L` `;` `'`（その列に即設置） |
| 1手戻す（+5秒） | `Q` / `Backspace` | `Q` / `Backspace` |

共通: `R` リトライ（同じシード）／ `N` 新しいシード／ `Esc` メニュー
タッチ（片手・デフォルト）: 列をタップで縦置き、フリックで子ぷよの向き（上下左右）
置く前の取り消し: 盤面の外まで引っぱって離す／2本目の指でタップ／（マウス）押したまま右クリック

タッチ（両手・オプションで切り替え）: 画面の左半分を横にスワイプで列、右半分をフリックで子ぷよの向き。右の指を離すと設置、左の指を先に離すと取り消し。左の指は押したままでよく、次のペアもそのまま列を決められる

タッチ（ボタン・オプションで切り替え）: 盤面の下に置き方22パターンのボタンが並ぶ。ボタンは軸ぷよが落ちる列の真下にあり、軸ぷよを中央に、子ぷよを小さくその向きに描く。押して離すと設置、ボタンの外までずらして離すと取り消し。列がずれない

1手戻すは画面の「1手戻す」ボタン

## オフラインで遊ぶ

一度オンラインで公開ページを開くと、ゲームが端末に保存され、以後はネットにつながっていなくても同じURLで遊べる（PWA）。
フォントは2回目に開いたときに保存されるので、オンラインのうちに2回開いておくとオフラインでも同じ見た目になる。
新しい版を公開すると、次にオンラインで開いたとき、メニュー画面で自動的に切り替わる（プレイ中には切り替わらない）。
Fire HD の Silk ブラウザでも、オフラインで表示できることを確認している。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ロジックの単体テスト（Vitest）
npm run build    # dist/ に出力
```

演出時間・色数・全消しボーナスなどの調整は `src/config.ts` の `CONFIG` を書き換える。
デフォルトから変えた場合、ランキングは別枠で記録される。

## 構成

```
src/
  config.ts          調整用の定数
  core/              ゲームロジック（描画に依存しない）
    tsumo.ts         シード→配ぷよ生成（チャレンジモード風。65536通り・128手ループ・8手ごとに色の数がそろう・初手2手は3色）
    field.ts         盤面・設置・13/14段目・重力
    chain.ts         連鎖の解決
    scoring.ts       得点計算
    game.ts          1手ごとの進行とアニメーション時間
  render/            Canvas 描画（宝石・エフェクト）
  input/controls.ts  キーボード・タッチ（片手／両手）
  input/pad.ts       タッチのボタン方式（置き方22パターンのボタン）
  audio/sound.ts     効果音（Web Audio で合成）
  storage.ts         オプションとローカルランキング（localStorage）
  main.ts            画面遷移と全体の組み立て
tests/core.test.ts   ロジックのテスト
public/icons/        アプリのアイコン（ホーム画面用）
vite.config.ts       ビルドとオフライン対応（PWA）の設定
```

## GitHub Pages で公開

`main` に push するたびに `.github/workflows/deploy.yml` がテスト・ビルドして公開する。
リポジトリの Settings → Pages → Source は「GitHub Actions」にしておく。
